# 视频提示词模板与随机版本

在 AI 会话中将原稿封装为项目可用的提示词。默认交付：**带占位符的原提示词、随机提示词、人物／场景／服饰各槽位的选中时文案与未选时文案**。这是当前口径，替代此前“只输出随机版和选中时文案”的规则。

保留同一脚本的台词、人数、产品件数、动作顺序、时长、镜头与声音。主提示词只保留固定脚本和视觉插入点；可选的具体视觉设定归槽位；随机提示词独立完整、整段替换主提示词。默认中文，不生成视频，不操作项目页面、数据库或发布接口。

## 输入与控制范围

- 用户指定只要某部分时按其范围交付；否则输出全部默认内容，不额外重贴未处理的输入原稿。
- 识别产品图、动作视频、人物图、场景图、服饰图的职责，沿用已知编号、角色与槽位顺序。槽位数由实际配置决定，不固定产品必须两图、人物必须图3。
- 固定脚本：对白逐字与顺序、说话人分工、人数、持物件数及归属、动作接触释放顺序、时长、比例、分辨率、模型、机位、声音与连续性。未提供的参数不强加。
- 可选视觉：身份外貌、妆发、服饰及首饰、环境与光影。除用户明确跨版本锁定外，原稿具体视觉设定用于未选时回退，不写在共享正文中锁死参考图。
- 用户已要求所有生成提示词无字幕，覆盖输入旧字幕设计；保留完整声音对白，删除字幕时间轴、样式及任何正向显示文字指令。
- 未提供图片时，不声称看过图片。可用原稿已有描述编写回退；缺少视觉细节时给出合理的文字默认设定，不编造产品事实。

## 产品引用通用化

产品图是每次调用的真实外观依据，不是某一固定SKU的永久锁定。默认移除文件名、型号、配色、特定图案及装饰细节等样例锚定，改为“本次参考图中的产品”。每次换图可换款换色，单条视频内固定。

- 主产品图仅锁定图中实际款式、真实配色、轮廓、结构、可见纹样、面料质感及装饰；不预设象牙白、黑色、浅金刺绣、双蝴蝶结或特定扣数。
- 补充图只补充同款产品其他视角下实际可见的结构，不把多视图当成多件商品，不复制文字、背景、白底或版式。
- 全文同步泛化：构图、动作、服装对比、照明与连续性也使用“本次产品颜色”“实际可见工艺”等；不在后文重新锁回6036、T35、象牙白或金色纹样，也不一律禁止某个可能正是参考款的颜色或材质。
- 产品颜色不参与人物服装的随机变色；服装与光线根据当前产品真实颜色适配，不通过改变产品来制造对比。不添加参考图不存在的装饰、材质参数、功效或价格。
- 用户明确要求固定型号时保留该要求；台词里已锁定的品牌或型号不擅自改字。通用化作用于可替换的视觉绑定，不改完整口播。

## 带占位符的原提示词（写入 prompt）

这是原稿的模板化版本，需要完整输出，不能用“原文已提供”省略；也不重复输出未经处理的原稿。

1. 保留固定脚本。将每个可选槽位控制的整段具体描述抽出，原位置只保留单张占位符 {{Mixed N}}。
2. 人物、场景、服饰分别独立插入，例如【人物】下只放 {{Mixed 3}}，而非“42岁女士，身份参考 {{Mixed 3}}”。人数、成年角色要求、职责、动作可放共享正文；具体年龄、脸型、颜色、地点等放入槽位文案。
3. 主产品和动作视频等必填引用在正文写通用用途说明；它们是素材编号引用，不要求选中／未选中两段文案。不要给必填槽位伪造未选状态。
4. 可选插入点是整段替换，选中时文案就是那一段，不是在完整原稿后额外追加。避免在正文和槽位里重复同一句绑定，也不要在多个章节重复插入同一槽位的整段说明。
5. 共享正文只保留两种状态都适用的展示要求。比如“不遮挡产品、支持既定手势”可以保留，“穿深棕裙、酒店木饰面”应移入对应未选时文案。
6. 使用界面支持的单张 {{Mixed N}} 作为条件段落插入点，不用带星号的整组引用或带点号的第N张引用替代；后两者没有相同的回退语义。

编号是模板中图片／视频槽位的序号，不是最终请求的素材编号。以当前实际配置为准；产品有两图且无其他槽位时，人物／场景／服饰可依次是图3／4／5。空槽位不占最终编号，由项目编译器重排，不手动改模板号。

## 槽位选中时／未选时文案

默认人物、场景、服饰三类各提供两段，多角色独立控制时按角色拆分。槽位配置为用户填充且可选（minCount=0），标题使用界面原名。

- **选中时文案**：只引用本槽位图片，描述其控制范围，不引用其他槽位。人物外貌由人物图决定；环境由场景图决定；服装款式、颜色、剪裁、可见质感及指定首饰由服饰图决定。不能叠加原稿的具体年龄、发型、地点或服装颜色。
- **未选时文案**：从原稿提取该维度完整的文字默认设定，不含任何素材占位符，不写“参考原图”“同上”或空白。不依赖另一个可选图存在，也不写随机抽样；它是主提示词没有图时的确定回退。
- 人物图不复制背景、手持物、其他人或服装；服饰图不改变人物脸、年龄、身材和动作；场景图不控制人物、产品与固定机位。配饰只有一个来源，归服饰图控制时人物图不接管同一首饰。
- 人数、角色职责、成年要求、台词、动作和镜头保持脚本事实。必要补光服务展示，不覆盖场景参考图整体光影。
- 每个槽位的两段分别独立代码块。原提示词中必须有对应插入点，否则两段文案不会生效。
- 必填产品／动作素材不列条件文案；用户明确要求把它们做成可选时，必须同时定义可执行的缺图策略，不能默默删除产品依据。

## 随机提示词（写入 randomPrompt）

独立完整，随机档会整段替换 prompt，不是追加主提示词，也不是把未选时文案拼成随机版。

- 保留产品图、必要动作视频及所有固定脚本。人物／场景／服饰可选图不传时，随机正文仍能直接编译；默认不引用这些可选槽位，避免未选时固定文案把随机方案重新锁死。
- 随机的含义是：提示视频模型每次生成前重新选择一套视觉方案，而非本次只抽出一个固定场景。只在用户明确要求单次具体方案时才输出固定抽样。
- 先打破原稿服装色彩、款式和场景锚定，再联动选择主色系、服装类别／廓形、妆发、人物气质、空间类型和真实光线。例子跨冷暖、鲜明与柔和配色、分体与连衣款、职场与生活及艺术空间，不形成封闭白名单或默认优先顺序。
- 每次优先探索不同服装主色系，并同时改变服装类别、妆发或场景类型中的至少两项。避免反复收敛到棕咖驼或相同修身裙；已知近期重复结果时明确避开其组合，没有历史时不假装知道上次结果。批量多版或多角色时明确区分配色和造型。
- 服装与当前产品真实颜色有明度或色相区分，不固定产品是浅色或深色，不通过修改商品配色实现搭配。
- 可以要求高探索度、多样化采样、跨风格重组，但文本不能修改 API temperature，不虚构已调整模型参数，也不承诺独立调用永不重复。
- 场景和服装必须支持固定动作。镜前转身需要合理镜面；拐弯行进需要连续可行路线；站定手势需要完整展示空间。不为随机创意改人数、动作或台词。
- 随机选择在开拍前完成，片内不换脸、换装、换景、换产品。人物身份与外貌、服装、光影、环境、持物关系全片连续。

## 全部版本无字幕、无背景音乐、无配音

主提示词与随机提示词开头明确“仅声音口播，不生成字幕或任何新增屏幕文字”，结尾再次要求：
“全程无字幕、无自动转写字幕、无逐字字幕、无翻译字幕、无贴字、无标题、无价格字卡、无水印、无UI；禁止把口播内容显示在画面上。”

原稿字幕样式、分段和时间轴全部移除，不与无字幕要求并存。参考素材的文字和版式不复制。完整对白仍原样用于声音，不新增BGM；原稿其他声音要求保留。不声称这些指令保证模型绝不生成字幕，不擅自增加后处理。

- 所有生成提示词均明确：无背景音乐、无BGM、无配乐、无歌曲底轨，无后期配音、无旁白、无画外音、无解说声、无合成人声或TTS，不继承参考视频音轨，不新增强调音效。
- 原稿有锁定口播时，保留画内指定角色与口型同步的现场同期口播；它是原脚本表演，不是另加的配音。仅保留该口播及必要的轻微自然环境声。多角色时只有原指定说话人发声，其他角色不跟读、不合唱。
- “不要配音”默认指禁止另配人声，不擅自删去原稿锁定对白或改成无声片。用户明确要求无声、无任何人声或静音时，以该明确要求为准。
- 两份完整正文都写入上述声音限制，不能只在槽位文案或其中一版声明。

## 固定输出顺序

直接输出以下内容，不加输入识别、转换总结、重复映射表或未处理原稿：

1. **原提示词（带占位符）**：一个完整代码块，人物／场景／服饰原位置为对应 {{Mixed N}} 插入点。
2. **随机提示词**：一个完整代码块。
3. **人物槽位（图号）—选中时文案**，随后 **人物槽位（图号）—未选时文案**。
4. **场景槽位（图号）—选中时文案**，随后 **场景槽位（图号）—未选时文案**。
5. **服饰槽位（图号）—选中时文案**，随后 **服饰槽位（图号）—未选时文案**。

每段文案单独代码块；多角色在标题注明角色。保留原稿【章节】风格，正文各自完整，不用“同上”“台词不变”或省略号替代内容。用户明确只要其中一项时再缩小范围。

## 交付核对

- 原提示词有每个可选槽位的实际插入点，正文没有残留与参考图冲突的具体视觉设定。
- 每个选中时文案只引用自己；每个未选时文案无占位符、内容完整，三类槽位八种组合都应能展开。
- 必填素材直接插编号，可选段落按状态替换；不能把图片序号、最终编号和段落插入点混为一谈。
- 随机提示词不依赖缺失的可选图，整段独立完整，跨色系与跨造型规则明确，片内稳定。
- 两份正文台词逐字相同且与输入一致，固定参数、人数、产品件数、动作因果、镜头及结束收音不漂移。
- 产品引用与全文描述通用化，换款换色无需重写；无擅造款号、配色、纹样、扣数、材质成分或功效。
- 两份正文都无字幕，无正向字幕指令残留。未见图片不声称观察过。
- 两份正文均禁止背景音乐和另加配音／旁白／画外音；有原口播时只允许指定画内角色的现场同期口播及必要自然环境声。
- 输入存在核心事实矛盾时只问必要问题；时长可行性问题简短指出，不擅自吞字、改秒数或保证实现。
