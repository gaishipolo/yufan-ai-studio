# 模板封装：占位与条件替换方法论

## 已核对的调用逻辑

模板封装页 /templates/specs 的主提示词保存到 prompt，随机提示词保存到 randomPrompt。可选槽位的选中时文案保存到 filledText，未选时文案保存到 emptyText。

- 用户填充且可选的槽位：minCount=0、maxCount=1。主提示词单张占位符是整段插入点。
- 选中素材：该处插入 filledText，其内部本槽位引用展开为实际素材编号。
- 未选素材：同一处插入 emptyText，不能残留任何缺失素材引用。
- 必填产品图或动作视频：不填会报错；引用直接插素材编号，不配置这两段文案。
- 随机档：compile_for 将 prompt 整段替换为 randomPrompt，再执行相同编译逻辑。常规可选人物／场景／服饰素材不传，所以随机正文默认不引用它们。
- 编译器是确定的纯函数，视频模型才按随机正文选择视觉方案。不要将未选时固定回退当作随机档实现。

作者写 {{Mixed N}}，N 是按 position 排序后的图片／视频槽位序号。normalize_refs 先将其转为内部 {{slot:key}}，编译时按实际素材数量分配最终编号。空可选槽位不占最终编号，不提前手动改模板号。

只用无修饰符的单张占位做条件段落。带星号是整组编号，带点号是第N张，不能用来替代同一段落的选中／未选回退。filledText 可以自引用本槽位，不能引用其他槽位；emptyText 不含任何槽位引用。

## 编译后的行为

主提示词只在三个位置各放一个可选插入点。选中人物图时，该处为参考图身份文案；未选时，该处直接成为30岁齐肩发的文字描述。两种状态只出现其中一段，不并排追加。

人物／场景／服饰三个槽位共有八种选中组合，全部应能展开。只有场景图选中时，模板图3会成为最终图2，人物和服饰以文字回退，不残留模板图3或图4引用。三图均未选时只保留产品图引用，主提示词仍完整。

随机提示词只引用必填产品图，不调用三类未选时文案。切换随机档后固定原稿人物、服装和场景不会混进随机方案。更换产品素材时两份正文都以本次图为准，不残留固定款号、配色、文件名或图案。

## 维护回归场景

- 所有输出均禁止字幕、背景音乐、后期配音、旁白、画外音和合成人声；原稿锁定口播保留为指定画内角色的现场同期声，其他角色不发声。不能因“不要配音”删除原脚本对白，也不能在随机版中遗漏声音限制。

- 输入带产品图、动作视频、场景图和礼服图：仍按默认顺序交付占位主提示词、随机提示词及两状态文案。保留真实槽位顺序，不因输入已有参考图而省略主提示词。
- 主提示词不要写“人物外貌参考 {{Mixed 2}}”同时另附整段 filledText；正确的是该处只放单张插入点。选中时整段替换，内部自引用只展开为实际编号。
- 主提示词人物可选而共享正文仍限定具体年龄、场景或服装颜色属于失败；应移入对应未选时文案。
- 随机档引用了人物／场景／服饰的固定回退、或依赖未传可选图属于失败；随机正文应独立完整。
- 原稿有6036、T35、象牙白、黑色、某花纹或特定扣数：视觉模板改为参考图通用描述，全段同步改构图／照明／服装对比／限制；锁定台词中的名字仍逐字保留。
- 原稿有三段白字字幕：两份正文都删除正向字幕设计，保留完整声音口播及无字幕要求。
- 必填产品图不输出选中／未选两段文案；可选人物／场景／服饰必须每项都有两段，emptyText 不含引用。
