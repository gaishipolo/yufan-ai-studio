# 模板封装驱动的工作台

**目标：** 原片封装了哪些功能，工作台就展示哪些功能；范围参数属于提示词封装，而非素材包。

**设计：** 同一原片可绑定任意数量的视频模板，每条模板是一项功能，用模板 ID 选择及提交，`rules.workbenchLabel` 提供可选显示名。现有 `defaultKind` 仅表示底层处理类型，不限制功能数量。未封装原片继续使用通用工作台。现有固定提示词模板默认没有范围参数；显式配置 `rules.scopeOptions` 时显示范围选项，通过 `{{ReplacementScope}}` 注入提示词。固定提示词正文与媒体占位符均保留。

**技术：** React、TypeScript、FastAPI、Python、Node 提示词编译器。
