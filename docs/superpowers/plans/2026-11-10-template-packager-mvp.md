# 会话调用视频模板封装 MVP

**Goal:** 将一个本地视频、参考图和多项功能提示词，通过可重试命令封装为模板库卡片。

**Architecture:** 新增独立 Python HTTP 客户端 `template_packager`，复用资产上传、素材包草稿与发布、视频模板创建接口。默认离线预检，`--apply` 执行；认证只从环境变量读取。以服务端稳定键防重、素材摘要去重、确定性素材包 UUID 和逐步原子进度文件支持恢复。首期单进程后端，不改 JSON 目录存储。

**Tech Stack:** Python、Pydantic、httpx、pytest。

用户已在本会话批准上轮方案并要求实现。直接在当前 `codex/video-template-remediation` 工作分支推进，保留已有文件。

- [x] 服务端防重：先添加重复创建及内容冲突测试，再使 `_append_record` 原子返回同键同内容记录、拒绝同键异内容。
- [x] 配置预检：添加文件缺失、用途、媒体槽位、范围参数、重复功能标识测试；实现严格配置模型和内容摘要。
- [x] HTTP 编排：测试多功能封装、响应丢失重试、内容变化阻断、账号隔离、旧服务拒绝；实现认证、能力检查、逐步状态与结果报告。
- [x] 命令入口：提供 `python -m template_packager manifest.json`、`--check-server`、`--apply`；增加实例及会话操作说明。
- [x] 验证：运行新测试、视频模板相关回归、Ruff 与 CLI 帮助/预检，检查最终差异；不提交真实生成任务。

验收：同视频多功能有不同模板 ID；提示词内容和图片用途保留；连续两次执行不增加模板或发布版本；超时后重试仍可恢复；默认不共享视频，配置 `shared: true` 才主动分享；报告含模板 ID、包版本、槽位清单、提示词摘要和工作台相对链接。

## 验证结果

2026-11-10：后端相关回归170项通过（封装器、模板防重、模板绑定、包草稿/发布、输入快照、授权守卫、跨账号素材、接口契约与架构）；前端相关回归47项通过。新增包 Mypy、修改文件 Ruff、`app export-openapi --check` 通过。真实 API 隔离联调已核对两项功能准备出的实际提示词；无外部生成请求。现有依赖发出 pytest-asyncio、Starlette 与 React Router 的弃用/未来版本提示。

独立代码复查发现并修复：远端模板改绑后不能依靠旧 fingerprint 假报成功；固定蓝本状态变化不影响原创建请求重试。两项修复已补先失败后通过的回归，复查无阻断问题。

运行限制：当前服务需重启加载新契约；调用者提供 YUFAN_API_TOKEN。未替用户重启已有服务或创建真实业务卡片（尚无指定视频/图片）。现有卡片标题沿用归档原片名称，配置 name 用于功能模板名称前缀。未创建提交，保留工作区已有修改。
