# 模板提示词画布交互迭代

执行：writing-plans / executing-plans，同一会话完成，不使用子代理。

## 目标与边界

1. 编辑状态允许切换封装功能，每个功能独立保留未保存草稿，保存只作用于当前功能。
2. 提示词输入区直接渲染带缩略图的引用标签；内部仍为原始 `{{Mixed N}}`，保留空白、换行、参数和全部其他文字。
3. 画布式工具栏、编号媒体条、光标附近的 @ 搜索菜单；分类浏览已引用/图片/视频，支持键盘、复制粘贴、原子删除与撤销重做。
4. 按用户补充：本轮仅调用既有图片上传接口，上传结果分功能展示为固定参考候选；不加入替换素材包，不将其自动编号或送入生成。模板持久绑定与切换产品逻辑后续迭代。上传图片仍存入素材库，编辑会话内切换功能保留上传结果。
5. 不附加图片描述，不改写固定提示词，不改动生成链路。

## 方案

采用一个原文驱动的轻量引用编辑器，将引用标签视为不可拆分的展示节点；DOM 读取时还原原始标记。与只读渲染或整套画布迁移相比，它能满足直接编辑，并保持当前模板接口与正文语义。上传暂不进入 `mediaOrder`，界面明确标注“待接入生成”，不让尚未接通的引用成为看似有效的生成输入。
