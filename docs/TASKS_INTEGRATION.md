# 任务中心与替换任务打通

日期：2026-11-06（Asia/Singapore）

`/tasks` 使用 `GET /api/v1/tasks/feed`，将数据库中的通用视频任务与归档盘中的替换任务合并展示。
原任务数据、生成执行器、提交与费用门禁、人工验收和回收站规则保持各自领域管理。
历史替换档案可直接读取，无需迁移或补建 VideoTask。

## 可见行为

- 默认展示全部可见来源；可按通用生成 / 模板替换、状态、关键词、时间或名称排序，再统一分页。
- “进行中”包含排队；替换的准备、上传、提交、生成与下载阶段保留精确状态文案。
- 待核对、等待免费、登录异常、连接待恢复、提交结果未知及成片文件待恢复进入“待处理”。
- “已完成”仅表示生成结果可用，不代替人工验收结论。
- 替换卡片携带 `/templates?kind=…&run=…`，进入模板库自动打开对应档案，继续复用成片播放、下载、核对与验收。
- 模板库创建、执行、验收、回收与恢复后，同时使统一列表缓存失效。列表**只在存在进行中任务时**每 5 秒轮询，
  页面隐藏即停，空闲时不发请求（跨设备新建的任务在窗口重新获得焦点时刷新）。
  侧栏角标走 `statsOnly=true`：只算统计、不组装条目，挂在每个页面也不会拉全量列表。
- 标题由后端统一生成（`sourceName · 类型 · 目标 · #短码`，原片名超过 18 字截断），模板页、核对弹窗、
  档案详情、删除确认与任务中心逐字相同。
- 侧栏角标统计本人的两类进行中任务。回收站中的替换任务不进入列表和角标。
- 批量勾选仍只作用于通用视频任务；通用任务原有下载、收藏等占位缺口不属于此次打通范围。

## 契约与权限

聚合接口要求 `task:read`。只有同时具备 `template:read` 才读取替换档案，且始终只读当前账号的档案；
`task:read:all` 只允许查看他人的通用任务，不扩展替换任务可见范围。
模板库原有操作继续独立检查 `template:use` / `template:review` 等权限。

记录使用 `video:<id>` 或 `replacement:<id>` 唯一键。替换档案 ID 和上游 LibTV 任务号不混用，
关键词可匹配替换目标、原片、档案 ID 与上游任务号。

聚合结果包含 `items / total / page / pageSize / stats / canReadAll / warnings`。
`statsOnly=true` 时只返回统计：`items` 为空，`total` 与 `stats` 和完整列表口径一致，供角标这类常驻组件使用。
统计受来源、关键词、范围及“仅可下载”筛选影响，不受状态标签与页码影响。
通用任务按同一排序提取前 `offset + limit` 条候选，与替换记录合并排序后再切页，避免两边各自分页导致遗漏。

归档盘不可用时仍展示可读的通用任务，并明确提示统计不包含替换任务；选择仅通用来源时不读取归档盘。
演示模式没有真实替换档案，会明确说明需要连接后端，不能用于真实任务联调验收。

## 验证

自动化覆盖混合列表分页与三种排序、统计口径、排队分组、待处理分组、上游任务号搜索、成片地址、
回收站恢复、产物丢失、权限与归属隔离、离线归档提示、来源筛选及档案深链接。

前端验证使用模拟 API 数据，后端测试使用隔离临时数据库与归档目录，未对真实 Z 盘执行生成、扣费或人工验收。
上线前仍需使用真实账号检查模板库提交后在任务中心出现、进度推进和成片播放下载。
