# 北京百炼视频渠道

替换工作台的「替换配置 → 模型渠道」可选择 LibTV、百炼 Wan 3.0 标准版或高速版。
单条与批量准备均保存当次渠道；后续更改选择不会改变已保存任务的渠道。

百炼输出为 720P，确认页面显示「阿里云 API 计费」，不提供 LibTV 的免费队列或积分加速选项。费用以阿里云账单为准，工作台不将百炼费用显示为 LibTV 积分。

## 服务端配置

在不提交版本库的 `api/.env` 中将 `bailian` 追加到 `AI_PROVIDERS`，配置：

```dotenv
BAILIAN_BASE_URL=https://llm-cz0qm1j8cl2weo19.cn-beijing.maas.aliyuncs.com/api/v1
BAILIAN_API_KEY=<北京业务空间的密钥>
BAILIAN_TIMEOUT_SEC=45
BAILIAN_DOWNLOAD_TIMEOUT_SEC=45
```

新增配置需要由后台进程重新加载。密钥只留在服务端，不返回到渠道目录，也不写入任务回执。

## 输入与结果

参考素材通过官方签名表单上传至百炼临时存储。上传和生成使用同一模型，标准版与高速版分别获取上传凭证。临时素材有效期 48 小时，重新准备可重新上传；生产高并发部署应换用自有 OSS 等稳定存储。

冻结的素材顺序会将 `{{Mixed N}}` 转成独立计数的「视频1」「图1」「音频1」。任务详情中的提示词与素材编号使用转换后的实际文本。

提交前校验素材摘要、大小、尺寸、比例、视频帧率及总时长；不满足要求时不提交付费生成。视频至少 16fps，单边 240–4096 像素；图片单边 240–8000 像素。参考视频总时长最多 15 秒，输入视频与输出视频合计不超过 30 秒，输出至少 2 秒。

成功后将成片下载到原任务工作区，再登记到现有归档存储。已下载文件可通过原任务的播放和下载入口读取。

## 重试与恢复

已返回任务号的任务只续查，不重复生成。提交前保存独占提交意图，超时或回执不明确时停止自动重提；明确的 HTTP 4xx 拒绝可重试。进程重启后可从已保存的百炼任务回执恢复任务号，并为已停止任务重新开启查询计时。

人工确认可能再次计费后，原未知回执会保留为 `bailian-reconfirmed-*.json`，再允许新一轮提交。正在提交的操作与回执归档共用任务锁，已受理回执不会被清除。
