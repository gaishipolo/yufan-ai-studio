## 4. 复核为干净的部分（避免重复劳动）

- **认证生命周期**：令牌不烤死权限 —— 每请求回库重解析（`api/deps.py` → `api/authn.py` → `modules/identity/principal.py`）；停用账号、会话被吊销、改密前签发的票立即生效（同秒边界见 2.10）。
- **越权面**：AST 扫过全部 60 个 POST/PUT/PATCH/DELETE 路由，**每个都挂了权限依赖**，无裸写接口。共享审批按全站/团队/小组三档判定，并用 `UPDATE … WHERE status='pending'` + `rowcount==1` 抢占。`scope=all` 仅在持 `:read:all` 时生效。
- **迁移链**：单 head `a7d3f0c85e21`，无缺失父节点、无分叉；唯一不可逆的 `b8e4c1f90d27` 的 `downgrade` 明确 raise，CI 的降级锚点与之相符；sqlite 上 `upgrade → downgrade 锚点 → upgrade` 实跑通过。
- **SSRF 护栏**：生图产物的 `persist_output` 每跳重跑 `_validate_asset_url`，生产强制配 `allowed_hosts`；libtv 与 pg_dump 都是 argv 数组、无 `shell=True`。（入库那条链是缺口，见 2.5。）
- **路径与打包**：本地存储 key 白名单 + 拒绝 `..` 段 + `is_relative_to`；归档 `within()` 拒绝绝对路径；zip 条目名过 `_safe_name` → 无 zip-slip。
- **队列**：DB 队列有 fencing token、条件领取与回执 `rowcount` 检查、续接落空有兜底。
- **契约**：四份生成物零差异；旧替换链端点（`/templates/replacement-*`、`/video-templates`、`/template-manifests`）全部 404。
- **生产自检**：弱密钥 / 匿名 / 无 `METRICS_TOKEN` / CORS 通配 / `TRUSTED_PROXIES=0.0.0.0/0` 四道闸都在。
- **前端权限判定**：`shared/access/evaluate.ts` 与后端 `CurrentUser.has` 的通配语义一致。
- **mock 打包**：演示口令与 mock 适配器不在生产 bundle（`dist/` 里 grep 不到 `admin@12345`）。
