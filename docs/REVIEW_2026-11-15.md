## 1. 复核为干净的部分（避免重复劳动）

- **认证生命周期**：令牌不烤死权限 —— 每请求回库重解析；停用账号、会话被吊销、改密前签发的票立即生效（同秒边界已修，见 `bf2a9a2`）。
- **越权面**：AST 扫过全部写路由，**每个都挂了权限依赖**，无裸写接口。共享审批按全站/团队/小组三档判定，并用 `UPDATE … WHERE status='pending'` + `rowcount==1` 抢占。
- **迁移链**：单 head，无缺失父节点、无分叉；唯一不可逆的 `b8e4c1f90d27` 的 `downgrade` 明确 raise，CI 锚点与之一致。`c4e9a1b7d230`（收藏按账号）在 sqlite 上跑过 `upgrade → 回填 → check → downgrade → upgrade`。
- **SSRF 护栏**：生图产物与入库下载都逐跳校验；生产强制配 `allowed_hosts`；libtv 与 pg_dump 都是 argv 数组、无 `shell=True`。
- **路径与打包**：本地存储 key 白名单 + 拒绝 `..` 段 + `is_relative_to`；归档 `within()` 拒绝绝对路径；zip 条目名过 `_safe_name`。
- **队列**：DB 队列有 fencing token、条件领取与回执 `rowcount` 检查、续接落空有兜底。
- **契约**：四份生成物零差异；旧替换链端点全部 404。
- **生产自检**：弱密钥 / 匿名 / 无 `METRICS_TOKEN` / CORS 通配 / `TRUSTED_PROXIES=0.0.0.0/0` 五道闸都在，且都在任何副作用之前。
- **前端权限判定**：`shared/access/evaluate.ts` 与后端 `CurrentUser.has` 的通配语义一致。
